# What is Helm?

Helm is a package manager for Kubernetes.

It helps us deploy and manage applications using
reusable packages called Helm Charts.

Examples:

- NGINX
- Prometheus
- Grafana
- Jenkins
- MySQL
Simple Comparison
Linux        → apt / yum
Python       → pip
Node.js      → npm
Kubernetes   → Helm
Interview Answer

Helm is a package manager for Kubernetes that uses Charts to package, configure, install, upgrade, and manage Kubernetes applications.
